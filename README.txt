# Instacart — Customer Purchasing Analysis

## Project Overview

This project explores customer purchasing behavior using a reduced dataset from Instacart, an online grocery delivery platform. The goal was to analyze shopping patterns, identify relevant trends, and generate insights that could support business decisions.

## Objectives

- Clean and prepare the datasets for analysis.
- Explore customer purchasing habits and identify relevant patterns.
- Analyze the data to better understand shopping behavior.
- Present findings that can support business recommendations.

## Methodology

- **Data Preprocessing:** Inspected datasets, identified data quality issues, and cleaned the data for analysis.
- **Exploratory Data Analysis (EDA):** Examined purchasing patterns and customer behavior using descriptive analysis.
- **Data Visualization:** Created visualizations to communicate findings and highlight relevant trends.
- **Business Insights:** Summarized the results to support a better understanding of customer purchasing habits.

## Tools & Technologies

Python · Pandas · NumPy · Matplotlib · Seaborn · Jupyter Notebook

## Key Skills

Data Cleaning · Data Preprocessing · Exploratory Data Analysis · Data Visualization · Customer Behavior Analysis · Business Insights

## Business Outcome

The analysis helped identify patterns in customer purchasing behavior and demonstrated how exploratory data analysis can turn raw transaction data into useful business insights. These findings can support decisions related to customer behavior and the shopping experience.

## Project Files

- `Instacart_Customer_Analysis.ipynb` — Notebook containing data cleaning, exploratory analysis, visualizations, and findings.
