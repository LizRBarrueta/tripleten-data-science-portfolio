# Film Junky Union — Movie Review Sentiment Classification

## Project Overview

This project focuses on building a machine learning model to classify movie reviews by sentiment. The goal is to automate the identification of positive and negative opinions in user reviews.

## Objectives

- Prepare and process movie review text data.
- Explore natural language processing techniques for sentiment analysis.
- Train and evaluate machine learning models for text classification.
- Assess model performance using the F1-score.

## Methodology

- **Text Preprocessing:** Prepared review text for machine learning.
- **Feature Extraction:** Used TF-IDF to represent text data as numerical features.
- **Model Training:** Explored machine learning approaches for sentiment classification.
- **Evaluation:** Assessed model performance using the F1-score.

## Tools & Technologies

Python · Pandas · NLTK · spaCy · Scikit-learn · LightGBM · TF-IDF

## Key Skills

Natural Language Processing (NLP) · Text Preprocessing · Sentiment Analysis · Text Vectorization · Classification · Model Evaluation

## Business Outcome

An automated sentiment classification model can help analyze large volumes of movie reviews and identify audience sentiment, supporting more efficient analysis of customer feedback.

- `Film_Junky_Union_Sentiment_Analysis.ipynb` — Notebook containing the text analysis, model development, and evaluation.
